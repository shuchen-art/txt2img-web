# txt2img⁻¹ — 本地 Web MVP

独立英文体验页：AI 构想一只羊，参与者根据简短指令作画，再接受 AI 的评判。每次退回后重新作画，最多提交四次。FastAPI 同时提供 API 和原生 Canvas 页面，原装置代码不参与运行。

## 启动

需要 Python 3.11 或更新版本；当前开发环境为 Python 3.14。首次安装：

```sh
cd /Users/leventunord/clea/portfolio/web/online
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
cp .env.example .env
```

在本机编辑 `.env`，填入有可用配额的 `DS_API_KEY`（也兼容 `DEEPSEEK_API_KEY`，两者都有时优先使用 `DS_API_KEY`）。不要将密钥提交到版本库或粘贴到网页。模型通过 `DEEPSEEK_MODEL` 配置，默认 `deepseek-flash`。也可通过进程环境变量提供配置，同名进程环境变量优先于 `.env`。已有 `.env` 时不要重新复制示例文件覆盖它。

出题和看图均调用 DeepSeek 官方 `https://api.deepseek.com/chat/completions`，使用 JSON Output，并在服务端校验输出结构。默认关闭 thinking，缩短交互等待；PNG 通过 base64 image_url 直接提交。自定义模型必须支持图像输入；`deepseek-v4-pro` 仅支持文本，不能用于本项目的绘画评判。参见 [图像输入文档](https://api-docs.deepseek.com/guides/vision/) 和 [JSON Output 文档](https://api-docs.deepseek.com/guides/json_mode/)。

之后用一个命令启动：

```sh
.venv/bin/python run.py
```

打开 http://127.0.0.1:8000 。按 `Ctrl+C` 停止。默认仅监听本机，必须使用一个进程，不能配置多个 workers。可使用 `--port 8002` 更换端口。

页面在没有密钥时仍可查看；点击 Start 会明确显示未连接提示，不会用预设反馈冒充实时 AI。出题只发生在点击 Start 后。配置更改需要重启服务。

HTTP 客户端使用正常的系统代理配置，并修正 HTTPX 无法解析的 `NO_PROXY` IPv6 回环地址写法。如果真实请求失败，终端仅记录错误类型或状态码；请检查密钥、模型权限、配额和本机到 DeepSeek API 的网络连接。HTTP 401/403 通常表示凭据或权限问题，402 表示余额不足，429 表示限流；这些错误均不会被当作画作拒绝，也不会消耗作品的轮次。

## 体验规则

- 固定黑笔，鼠标、触屏和触控笔共用 Pointer Events；提供撤销、清空。画布聚焦时支持 Cmd/Ctrl+Z。
- 画布使用固定 960×960 内部分辨率，显示与下载均为 1:1 正方形；CSS 自适应显示，缩放和旋转不会重设画布。
- 只提交非空白 PNG。服务端限制原始 PNG 不超过 2 MiB、尺寸为 16–2048 px，拒绝动画、损坏文件和透明空白图。
- 前三轮的评判提示为任一评分 ≥4 则接受；第四轮为 ≥3。评分和裁决由 AI 生成，页面只显示反馈，不显示分数或隐藏目标。
- 第三轮拒绝后明确显示 `This is your last try.`。第四轮无论通过与否都结束。
- 每轮指令和已提交画作按顺序保留。退回后自动追加新指令和空白画布，并滚动到新指令；历史画作是独立 PNG，不受撤销、清空或缩放影响。可自由向上回看。
- 结束后保留全部记录与最终反馈，不再生成画布。Save drawing 只下载最后一张白底 PNG；Start again 释放旧会话、清空页面记录并创建新会话。
- 提交失败时画布暂时锁定，保留图片与提交编号；Retry submit 用同一编号恢复结果，避免网络断开造成重复计次或重复追加记录。会话过期时可保存当前画作并重新开始。
- 不提供跨刷新恢复。刷新会回到待机；旧会话按过期规则释放。历史记录仅存于当前页面内存。
- 页面为黑白单列，最大宽度 640px，手机左右留白 16px。页头、指令区、画作及操作栏使用连续细线分格；指令内部不分隔，上下各留白 24px。PT Mono Regular、OFL 许可证及指定 SVG logo 均位于 `static/`，无外部字体或图片请求。滚动遵循系统的减少动态效果设置。

## 服务端接口与数据

| 接口 | 输入 | 输出 |
| --- | --- | --- |
| `POST /api/sessions` | 无 | `session_id`, `round: 1`, `instructions: string[]` |
| `POST /api/sessions/{id}/drawings` | JSON：`submission_id`（UUID）、`round`（1–4）、`image_base64`（纯 PNG base64，不含 data URL 前缀） | `round`, `next_round`（或 null）, `state: retry / accepted / terminated`, `feedback: string[]` |
| `DELETE /api/sessions/{id}` | 无 | 204；重复删除也成功 |

错误统一为 `{"error": {"code": "…", "message": "…"}}`。过期会话为 410；正在评判、已结束、轮次不匹配或修改已用提交编号为 409；超时为 504；AI 配置/连接/响应问题为 502 或 503；无效图片/请求为 400、413 或 422。

`round` 防止旧页面或延迟请求误占下一轮。同一提交编号与相同图片重复请求直接返回缓存结果，即使已经进入后续轮次或结束；同一编号换图片会被拒绝。每个会话仅允许一个评判请求执行。

会话保存于进程内存，包括隐藏构想、已确认的完整模型消息、历史图像和提交结果；不写数据库、图片文件或内容日志。评判失败不提交历史，也不增加轮次。服务端 30 分钟未收到会话操作后会话过期；本地画布操作不发送心跳。定时清理每分钟运行一次，API 请求时也检查过期。重启服务会清除所有会话。

画作会发送到 DeepSeek；应用自己的内存清理不代表第三方服务的数据保留政策。浏览器收到的 API 数据不含密钥、隐藏构想或评分。MVP 面向本地使用，公开上线之前需要另行设计配额、限流、访问策略和持久化方式。

## 验证

```sh
.venv/bin/python -m pytest -q
```

测试通过模拟 HTTP 传输验证 DeepSeek 图片请求与会话消息，不读取真实密钥、不产生 AI 费用。API 测试覆盖所有结束轮次、重放、并发、过期、异常恢复和输入校验；适配器测试同时检查认证、额度、限流、超时、空 JSON、截断响应及配置兼容。

可选的真实 API 检查（读取 `.env`，会使用少量 DeepSeek 配额）：

```sh
.venv/bin/python tests/live_check.py
```

该脚本通过应用自己的 API 完成一次出题、最多两次合成测试画作评判和重复提交检查，不输出密钥、隐藏目标或评分；结束后释放会话。它不会随 pytest 自动运行。

浏览器验收专用服务：

```sh
.venv/bin/python tests/browser_server.py
```

打开 http://127.0.0.1:8001 。该页顶部明确标记 **TEST FIXTURE — no live AI**，不会被正式入口启用。第一次提交模拟网络失败，重试成功；首个会话四轮后终止，第二个会话首轮接受，随后交替。可据此检查画布、清空、重试、最终状态、保存图片和重新开始。

额外异常场景（分别启动）：

```sh
.venv/bin/python tests/browser_server.py --scenario lost-response --port 8002
.venv/bin/python tests/browser_server.py --scenario expired --port 8003
```

`lost-response` 在服务端已确认第一张画后模拟响应丢失，用于确认重试恢复缓存结果且只追加一次记录；`expired` 在提交时模拟会话过期，用于检查画作保存与重新开始。

## 代码边界

`app.py` 负责会话、轮次和图片校验；`ai_service.py` 负责 DeepSeek 图像请求和结构化响应校验；`prompts/` 是修正占位符、阈值重叠和赞美冲突后的独立提示词；`static/` 是页面、样式和绘画交互。`requirements-lock.txt` 记录验收环境所需的依赖闭包；`requirements.txt` 与 `requirements-dev.txt` 用于主动升级依赖后重新测试、生成锁定清单。原装置参考代码不参与在线版本运行。

本版本没有公开部署、收据打印、画廊、摄像头上传、账号或统计系统。
